# Security Policy

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub issues, discussions or pull requests.

Use GitHub's private vulnerability reporting instead: open the **Security** tab of the affected repository and click **Report a vulnerability**. Only the Nextendo Network maintainers can see these reports.

Please include:

- the affected repository, component or service (for example the account server, a game server, the emulator or the app);
- the version or commit, if you know it;
- steps to reproduce, and a proof of concept if you have one;
- the impact you expect (account takeover, data exposure, remote code execution, denial of service, ...).

## What to expect

- We acknowledge new reports within 72 hours.
- We keep you updated while we investigate and fix the issue.
- We credit reporters in the fix announcement, unless you prefer to stay anonymous.

Please give us reasonable time to fix the issue before you disclose it publicly, and do not access, modify or delete other users' data while testing.

## Scope

All repositories of the NextendoNetwork organization and the services running on nextendo.network.
